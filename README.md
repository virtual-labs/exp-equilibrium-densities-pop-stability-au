### About the Experiment 

This experiment explores how a predator's hunting efficiency impacts the long-term balance between predator and prey populations. Using the interactive simulation, you will observe how changes in hunting success can either stabilize an ecosystem at steady numbers (equilibrium) or cause chaotic population swings.
